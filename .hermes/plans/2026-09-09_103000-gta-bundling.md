## Bundle Design (data)

Define ~4 bundles in a new header `source/gta_bundles_data.hpp`. Each bundle references existing cheats by **name string** (resolved against CATEGORIES at runtime via a helper) so we don't duplicate combo arrays.

```cpp
// source/gta_bundles_data.hpp
#pragma once
#include "gta_cheats_data.hpp"
#include <vector>

struct BundleDef {
    const char* title;          // e.g. "Bundling A"
    const char* desc;           // short subtitle shown in detail screen
    const char* const* cheatNames;  // names, resolved at runtime
    u32 count;
};

// resolve a cheat name -> CheatEntry* (searches all categories)
static inline const CheatEntry* findCheat(const char* name) {
    for (u32 c = 0; c < CATEGORY_COUNT; c++)
        for (u32 i = 0; i < CATEGORIES[c].count; i++)
            if (strcmp(CATEGORIES[c].items[i].name, name) == 0)
                return &CATEGORIES[c].items[i];
    return nullptr;
}
```

```cpp
struct Injector {
    bool playing = false;
    std::vector<const CheatEntry*> queue;   // sequence of cheats
    size_t qIndex = 0;                       // current cheat in queue
    const CheatEntry* cur = nullptr;         // current combo
    int idx = 0, hold = 0;
    static constexpr int HOLD_FRAMES = 2;

    // play a single cheat (existing behavior)
    void start(const CheatEntry* c) { queue.clear(); queue.push_back(c); begin(); }
    // play a list of cheats (bundles)
    void startSequence(const std::vector<const CheatEntry*>& seq) { queue = seq; qIndex = 0; begin(); }
    void begin() { playing = !queue.empty(); idx = 0; hold = 0; cur = playing ? queue[0] : nullptr; }
    void stop() { playing = false; cur = nullptr; queue.clear(); }
    bool active() const { return playing; }
    size_t remaining() const { return queue.empty() ? 0 : queue.size() - qIndex; }

    void setButtons(u64 mask) {
        HiddbgDebugPadAutoPilotState state = {}; state.buttons = (u32)mask;
        hiddbgSetDebugPadAutoPilotState(&state);
    }

    void tick() {
        if (!playing || !cur) return;
        if (hold == 0) setButtons(cur->combo[idx]);
        if (++hold >= HOLD_FRAMES) {
            setButtons(0);
            idx++;
            if (idx >= (int)cur->len) {  // this cheat done -> next in queue
                idx = 0; qIndex++;
                if (qIndex < queue.size()) { cur = queue[qIndex]; }
                else { setButtons(0); stop(); }
            }
        }
    }
};
```

```cpp
class GuiBundleDetail : public tsl::Gui {
public:
    GuiBundleDetail(int bundleIdx) : m_bundle(&BUNDLES[bundleIdx]) {}

    virtual tsl::elm::Element* createUI() override {
        auto frame = new tsl::elm::OverlayFrame(m_bundle->title, "N cheats · Confirm to run");
        auto list  = new tsl::elm::List();

        // resolve bundle -> ordered list of CheatEntry*, skipping unknown names
        std::vector<const CheatEntry*> order;   // built here, reused by Confirm
        for (u32 i = 0; i < m_bundle->count; i++) {
            const CheatEntry* c = findCheat(m_bundle->cheatNames[i]);
            if (!c) continue;
            order.push_back(c);
            list->addItem(new tsl::elm::ListItem(c->name));   // read-only row
        }

        auto confirm = new tsl::elm::ListItem("Confirm ▶");
        confirm->setClickListener([this, order](u64) {
            if (!order.empty()) gInjector.startSequence(order);   // run ALL, no toggles
            return true;
        });
        list->addItem(confirm);

        frame->setContent(list);
        return frame;
    }
    virtual void update() override { gInjector.tick(); }
    virtual bool handleInput(u64 keysDown, u64 keysHeld,
        const HidTouchState &touch, HidAnalogStickState l, HidAnalogStickState r) override {
        return false;
    }
private:
    const BundleDef* m_bundle;
};
```

## Risks, Tradeoffs & Open Questions

- **hid:dbg availability** in applet context is the known environment risk (documented in skill §5). If denied, no injection works at all — bundling won't change that. Fallback = sysmodule companion (out of scope here).
- **Wait between combos:** GTA SA may need ~100–300ms between separate cheats or the 2nd combo is swallowed. Consider a `BETWEEN_FRAMES` gap (e.g. `idx==0 && qIndex>0` → hold idle N frames before pressing first button of next combo). Mark as tunable constant `BETWEEN_FRAMES` (default ~60 = 1s @60fps). *Open: confirm on-device — start with 0, tune if needed.*
- **Bundle names must exactly match DB** — mitigated by host-side checker.
- **No runtime test off-device** — final validation is user testing on Switch.
- **Bundle order fixed at design time** — "select a bundle → Confirm" runs every cheat in the bundle in order. If the user later wants per-cheat selection, that's the toggle UI which was explicitly dropped.
